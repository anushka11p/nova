# Nova Mobile (Android + iOS)

One Expo / React Native codebase for Android and iOS. The jaundice model runs **on the device**
(TensorFlow Lite via `react-native-fast-tflite`), so screening works offline and photos never leave the phone.

## Flow

Take or choose a photo → centre-crop to square → resize to 224×224 → on-device model → probability of
jaundice → risk band (Normal / Moderate / High) with a recommendation.

The threshold and model name come from `assets/model/model_metrics.json`, written by `ml/train.py`
alongside `assets/model/nova_jaundice.tflite`. Retrain and the app picks up the new model on the next build.

## Run

The app uses native modules, so it needs a development build (Expo Go will not work).

```bash
npm install
npm run android     # builds, installs and launches on an emulator or USB device
npm run ios         # needs Xcode + an iOS Simulator runtime (Xcode → Settings → Components)
```

After the first build, `npx expo start` is enough for JS-only changes.

### Cloud builds (no local Xcode / Android Studio)

```bash
npx eas-cli@latest build --platform android --profile preview   # installable .apk
npx eas-cli@latest build --platform ios                          # needs an Apple Developer account
```

## Files

- `App.tsx` — the screen (capture, result card, disclaimer)
- `src/screening.ts` — preprocessing, inference and risk banding
- `assets/model/` — generated by `ml/train.py`; do not edit by hand
